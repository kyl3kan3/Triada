# Triada Advisors — Website Rebuild

A dependency-free static rebuild of [triadaadvisors.com](https://www.triadaadvisors.com/)
for Triada Advisors, Columbia, Illinois.

## Design system

Agency-grade art direction, no frameworks and no external assets:

- **Brand motif** — a "triad" mark (three nested triangles) used as the logo,
  favicon (inline SVG data URI), hero art, and quote ornament; a faint
  triangle lattice texture runs through the dark bands.
- **Palette** — ink navy `#0c1f33`, champagne gold `#b08d3f`/`#c2a25c`,
  porcelain `#f7f5f0` with a warm paper white.
- **Typography** — editorial display serif (Didot/Bodoni/Playfair stack with
  Georgia fallback) with italic gold accent words; letterspaced small-caps
  kickers and nav; humanist sans body.
- **Custom iconography** — hand-drawn inline SVG line icons (compass, growth
  path, shield, ledger) on a 48px/1.5px-stroke grid.
- **Micro-interactions** — scroll-reveal choreography with stagger delays,
  count-up stats, sticky header with scroll shadow, animated nav underlines,
  card hover lifts, hero scroll cue. All motion respects
  `prefers-reduced-motion`.
- **SEO/a11y** — JSON-LD FinancialService schema, OG tags, canonical URLs,
  skip link, ARIA labeling, WCAG-conscious contrast, print styles.

## Structure

Every page is generated by `build.py` (Python 3 standard library only) so the
header, navigation, footer, and — most importantly — the regulatory
disclosures stay identical on every page.

```
build.py                  # zero-dependency static site generator (all content lives here)
assets/css/styles.css     # site-wide styles
index.html                # generated — do not edit by hand
about-us/  our-solutions/  your-experience/  team/  blog/  events/  contact-us/
team/<member>/            # one page per team member
about/  contact/          # redirect stubs preserving legacy URLs
```

To change content, edit `build.py` and re-run:

```
python3 build.py
```

Deploys on any static host (GitHub Pages, Netlify, S3/CloudFront). URLs use
trailing-slash directory paths matching the original site (`/about-us/`,
`/team/calvin-neeman/`, etc.).

## ⚠️ Verify before publishing

The live site blocks automated access, so this rebuild was assembled from
indexed/public information. A compliance officer should confirm:

1. **State registration list** — `build.py` contains
   `STATE_DISCLOSURE_PLACEHOLDER`. Replace it with the exact list of states
   in which the firm's LPL registered representatives are registered. **The
   site must not go live with the placeholder in place.**
2. **Disclosure wording** — confirm the footer disclosure text matches the
   firm's current LPL-approved language verbatim.
3. **Team bios and titles** — bios are short summaries; review each and add
   photos (replace the initials avatars).
4. **Page copy** — the copy is a faithful rewrite of the firm's messaging,
   not a word-for-word copy of the old site. Review against the original.
5. **Contact form** — currently a `mailto:` fallback. Wire it to your CRM or
   a form service before launch, and confirm the form meets your
   books-and-records/archiving requirements.
6. **Blog & events** — the original site's posts and events were not
   migrated; those sections are ready-to-fill placeholders.
